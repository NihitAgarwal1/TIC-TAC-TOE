Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.
Two players take turns playing as X and O on a 3×3 grid. The game automatically detects a winner and allows you to reset and play again.

index.html
Creates the game layout
Contains:
Game title
3×3 grid using buttons
Result display area
Reset button
Links the CSS and JavaScript files 

style.css
Styles the game board and buttons
Adds:
Background image
Hover and uplift animation on buttons
Centered layout
Responsive grid design

script.js
Handles the game logic
Features:
Alternates turns between X and O
Checks all winning patterns
Displays the winner
Disables cells after win
Resets the game on button click
